# Willowbrook — Live Build Progress

A cozy little town in the spirit of Animal Crossing. Built in Three.js so it runs in any browser.

## Status

- Wave 0: scaffolding
- Wave 1: terrain + player + first villager + time-of-day
- Wave 2: buildings + interiors
- Wave 3: inventory + tools + economy
- Wave 4: more villagers + routines + dialogue
- Wave 5: audio pass
- Wave 6: polish (particles, weather, lighting curves)
- Videos: 3 contextual cinematics via mmx-cli

## How to play

Open `index.html` via a local static server (e.g. `python3 -m http.server`).

## How to follow the build

This page updates as waves ship. Each wave has a short note + a critic verdict.
